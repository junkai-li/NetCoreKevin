根目录通过 NetCoreKevin.sln 将四大子域统一编排：App（WebApi + Application + Domain + RepositorieRps）作为业务入口，依赖 Kevin/ 下的核心框架模块（kevin.Domain、kevin.Application、kevin.EntityFrameworkCore 以及 Cache/CAP/Consul/DistributedLock/Permission/SignalR/Hangfire/AI.AgentFramework/RAG/SMS/Email 等可插拔模块），tests 通过 Testing.Shared 对 App 与 Kevin 进行单元/集成测试，frontend_vue 通过 REST API 与后端交互，docs_and_init_data 提供系统启动所需的静态资源与 Excel 初始化数据；各层之间以 DDD 分层与模块化依赖边界约束，运行时由 App.WebApi 启动并加载 kevin.*.Module 中的 IModuleConfigTasks 完成服务注册与任务调度。
