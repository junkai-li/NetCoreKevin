项目采用 Vue CLI 5 + Vue 3 Composition API 的单页架构：`src/main.js` 通过 `createApp` 挂载根组件 `App.vue`，并全局注册 ant-design-vue、vue-router、dayjs（中文）及 ResizeObserver polyfill；`App.vue` 使用 `a-config-provider` 包裹路由视图，并通过 CSS 变量 `--accent` 动态注入主题色。路由集中在 `src/router/index.js`，以 `/home` 为布局父路由，按功能域划分子路由（user/system/my/aimanagement/position/department），并通过 `meta.requiresAuth` 配合 `beforeEach` 守卫实现基于 `localStorage.token` 的登录鉴权。API 层按业务域拆分到 `src/api/`（ai、organizational、baseapi、code_generator、dic、file、log、message、permission、roleapi、tenant、userapi），统一通过 `src/utils/http.js` 封装的 Axios 实例发起请求，该实例在请求拦截器中自动附加 `Authorization: Bearer <token>`，在响应拦截器中处理 401/403/400 错误、文件下载流以及服务端返回的新 token 刷新。页面组件位于 `src/pages/`，按功能域再分子目录（ai、organizational），通用 UI 片段抽取为 `src/components/`（如 UserAddEdit、PermissionManager、FileUpload），样式拆分为 `src/css/` 下的主题与页面级 CSS。构建配置由 `vue.config.js` 定义开发代理（将 `/VarApi` 转发至 `http://localhost:9901` 并去除前缀），多环境通过 `.env.development`、`.env.pre` 等环境变量区分后端地址。
