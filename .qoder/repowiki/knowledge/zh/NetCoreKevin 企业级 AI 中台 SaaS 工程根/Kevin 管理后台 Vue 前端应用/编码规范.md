- API 调用按业务域拆分为独立 JS 文件（如 ai/*.js、organizational/*.js），统一通过 `../utils/http` 导出的 Axios 实例发起请求，避免在页面中直接 import axios。
- 路由集中声明于 `src/router/index.js`，受保护页面通过在路由 meta 中标记 `requiresAuth: true`，并由 `beforeEach` 统一校验 `localStorage.token` 后跳转登录。
- HTTP 异常处理集中在 `utils/http.js` 的响应拦截器中，对 401 清理本地缓存并重定向到 `/login?redirect=...`，对 400/403 通过 antd message 提示后 reject Promise。
- 页面组件统一使用 `<script setup>` 语法与 Vue 3 Composition API，样式通过独立的 `.css` 文件引入或在 `<style scoped>` 中编写。
- 主题色通过 CSS 自定义属性 `--accent` 暴露给 `App.vue`，再由 antd `a-config-provider` 的 `colorPrimary` 动态绑定，实现运行时换肤。
