根目录通过 NetCoreKevin.sln 的 Solution Folders（App / Kevin / Test / Module）对 30+ 个 .csproj 进行分组：App.WebApi 作为唯一启动项目，按 Domain→Application→RepositorieRps→WebApi 四层依赖 kevin.Domain/kevin.Application/kevin.RepositorieRps 及 kevin.Module/* 下的横切能力（Cache、CAP、Consul、DistributedLock、Permission、SignalR、Hangfire、AI.AgentFramework、RAG、SMS、Email、Authentication.Jwt、Asr、CodeGenerator、SnowflakeId 等），运行时由 WebApi 加载各 kevin.*.Module 中的 IModuleConfigTasks 完成服务注册；tests 通过 Testing.Shared 同时覆盖 App 与 Kevin 层；frontend_vue 仅通过 REST API 与后端交互，不反向依赖 .NET 工程；docs_and_init_data 提供系统启动所需的静态资源与 Excel 初始化数据。docker-compose.yml 用于编排 MySQL、Redis、Qdrant、Hangfire、Consul 等外部依赖，使整套工程可在本地一键拉起。
