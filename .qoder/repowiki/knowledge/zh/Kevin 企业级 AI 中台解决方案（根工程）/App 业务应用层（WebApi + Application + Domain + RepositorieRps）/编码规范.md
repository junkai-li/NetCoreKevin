- 每个 csproj 项目均提供 `ModuleInitializer : IModuleInitializer`，在 Initialize 中通过 `IocHelper.BatchAddScopeds` 批量注册服务或仓储到 IServiceCollection。
- API 控制器按版本号划分目录（v1、v2），并使用 `[ApiVersion]` 与 `[Route("api/[controller]/[action]")]` 约定路由，同时通过 `[SkipAuthority]` 等特性控制权限。
- 领域实体继承基类 `CUD_User`，并使用 `[Table]`、`[Description]`、`[StringLength]` 等 DataAnnotations 标注表名、字段说明与长度约束。
- 仓储接口位于 `Domain/Interfaces/Repositorie/v1`，命名形如 `I*Rp` 并继承 `IRepository<T, long>`；仓储实现在 `RepositorieRps/Repositories/v1`，继承通用 `Repository<T, TId>`。
- 应用服务位于 `Application/Services/v1`，继承 `BaseService` 并通过构造函数注入对应的 `I*Rp` 仓储接口，以异步方法返回 `Task<bool>` 或分页 DTO。
- 通过 GlobalUsings.cs 集中声明跨文件的全局 using（如 App.Domain.Entities、kevin.Share.Dtos、Microsoft.EntityFrameworkCore 等），避免在每个文件中重复引入。
