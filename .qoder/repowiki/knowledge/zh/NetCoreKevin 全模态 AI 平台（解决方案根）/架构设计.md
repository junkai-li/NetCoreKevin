根目录不承载业务逻辑，仅做跨子模块的装配与编排：
- NetCoreKevin.sln 通过 Solution Folders（App / Kevin / Test / Module）对 30+ 个 .csproj 分组，App.WebApi 作为唯一启动项目，按 Domain→Application→RepositorieRps→WebApi 四层依赖 kevin.Domain/kevin.Application/kevin.RepositorieRps 及 kevin.Module/* 下的横切能力；运行时 WebApi 加载各 kevin.*.Module 中的 IModuleConfigTasks 完成服务注册。
- frontend_vue 仅通过 REST API 与后端交互，不反向依赖 .NET 工程；docs_and_init_data 提供系统初始化所需的静态资源与 Excel 数据。
- docker-compose.yml 编排 MySQL、Redis、Qdrant、Hangfire、Consul 等外部依赖，使整套工程可在本地一键拉起。
- tests 通过 Testing.Shared 同时覆盖 App 与 Kevin 层，保持与生产代码相同的分层边界。
- 当前新增的全模态能力（音频输入 + 文生图输出、OpenAI 兼容 Key 用户级落库）严格遵循上述分层：Domain 实体 → kevin.Module 独立 csproj → Application 服务 → EF+Config → Vue 页面，新增能力封装为独立模块而不侵入既有代码路径。
