一、系统概述1. Overview

1.1 系统简介1.1 Introduction

AI智能体后台管理系统AI Agent Admin System 是一款基于 Vue 3 + Ant Design Vue 构建的企业级后台管理平台，主要用于管理AI智能体、用户、权限、知识库等核心业务模块。is an enterprise-grade admin platform built with Vue 3 + Ant Design Vue, primarily used for managing AI agents, users, permissions, knowledge bases, and other core business modules.

四、核心功能详解4. Core Features

4.1 文件上传4.1 File Upload

在AI聊天页面支持文件上传功能：File upload in AI chat page:

  • 点击上传按钮选择文件Click upload button to select files
  • 发送消息时自动携带文件信息Files automatically attached to messages
  • 消息下方展示文件链接，支持点击下载File links below messages, click to download
  • 发送成功后自动清空上传列表Upload list auto-cleared after sending

4.2 链接高亮4.2 Link Highlighting

消息内容中的URL会自动高亮并可点击：支持 http:// 和 https:// 协议，自动识别Markdown格式中的链接，点击后在新窗口打开URLs in messages are auto-highlighted and clickable: supports http:// and https://, auto-detects Markdown links, opens in new window

4.3 消息复制4.3 Message Copy

所有消息内容都支持复制：点击消息旁的复制按钮，支持现代浏览器剪贴板API，旧浏览器自动降级处理All messages support copy: click the copy button, supports modern Clipboard API, graceful degradation for older browsers

4.4 智能体安全拦截4.4 Agent Security Interception

智能体支持安全拦截功能：开启状态对Python脚本和Shell命令内容进行安全拦截，默认状态开启，配置位置：智能体编辑页面的 IsSecurityIntercept 开关Agents support security interception: enabled by default, intercepts dangerous Python scripts and Shell commands, configured via IsSecurityIntercept toggle on agent edit page

六、登录与权限6. Login & Permissions

6.1 登录流程6.1 Login Flow

  1. 访问系统首页自动跳转至登录页Accessing home page auto-redirects to login
  2. 输入账号密码进行登录Enter username and password
  3. 登录成功后跳转至仪表盘Redirect to dashboard after login

6.2 权限验证6.2 Permission Verification

  • 系统采用路由守卫进行权限验证Route guards for permission verification
  • 未登录用户自动重定向至登录页Unauthenticated users redirect to login
  • 用户信息缓存有效期为10分钟User info cache valid for 10 minutes

八、常见问题8. FAQ

页面加载异常Page Load Issues

页面空白或加载缓慢Blank page or slow loading

  1. 检查网络连接Check network connection
  2. 清除浏览器缓存Clear browser cache
  3. 检查控制台错误信息Check console errors
  4. 联系系统管理员Contact system administrator

登录失败Login Failure

  1. 检查账号密码是否正确Check username/password
  2. 检查账号是否被禁用Check if account is disabled
  3. 联系管理员重置密码Contact admin to reset password

文件上传失败File Upload Failure

  1. 检查文件大小（建议不超过10MB）Check file size (recommended ≤10MB)
  2. 检查文件格式是否支持Check file format support
  3. 检查网络连接Check network connection

分页功能异常Pagination Issues

  1. 刷新页面重新加载Refresh page
  2. 检查分页参数配置Check pagination config
  3. 联系开发人员排查接口问题Contact developer to check API
